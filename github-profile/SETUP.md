# Make your GitHub profile show this README

GitHub displays a special profile README only when its repository has **exactly the same name as your GitHub username**.

1. Sign in to [GitHub](https://github.com/new).
2. Create a **Public** repository named `VaibhavDureja` (exact capitalization of your username).
3. Tick **Add a README file**, then create the repository.
4. Return to ChatGPT and tell the assistant: `The VaibhavDureja profile repository is created — publish my prepared README.`
5. The connected GitHub assistant can then replace the default README with the professional profile text in this package.

No command line, API key, or paid plan is necessary for these steps.
