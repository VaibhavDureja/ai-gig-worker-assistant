# Project scope: feasibility first

ParkCast is a proof of concept, not a claim of universal YouTube-in-CarPlay compatibility.

**Milestone 1:** Cast a consenting Android phone screen to a normal web browser on the same LAN. (Source implementation complete, physical tests pending.)

**Milestone 2:** Measure latency and stability, improve transport, and test aftermarket Android head units that provide independent browsers.

**Milestone 3:** Investigate official vendor-approved parked entertainment SDKs. Apple CarPlay video requires an app-specific entitlement and compatible vehicle hardware. Google Android Auto's public parked-app category restrictions must be checked again before any product claim or distribution.

**Milestone 4:** Only after compatibility is proven, add optional paid distribution such as a time-limited trial and a one-time purchase.

Safety principle: never encourage viewing or interacting with video content while a vehicle is moving. The demo itself cannot verify parked status; therefore its instructions require parked usage.
